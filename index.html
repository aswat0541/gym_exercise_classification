🏋️ Gym Exercise Classification

Personalized Workout Recommendation & Risk Flagging System using ML + DL

📌 Problem Statement

Title: Personalized Workout Recommendation and Risk Flagging System Using Machine Learning

Problem: Many individuals engage in physical exercises that are incompatible with their personal health conditions, leading to increased risk of injury, exacerbation of existing medical issues, or adverse health outcomes. Common fitness apps and generic workout plans do not account for individual physiological parameters such as age, BMI, heart rate patterns, or pre-existing conditions. This lack of personalization poses a significant safety concern, especially for beginners or those with underlying health risks.

Objective: To develop a machine learning-based classification system that analyzes user health data (e.g., age, BMI, heart rate, workout history) and recommends suitable workout types while flagging exercises that should be avoided. The system aims to improve exercise safety and effectiveness by providing personalized, data-driven guidance.

Outcome: A predictive model that classifies users into appropriate exercise categories (e.g., cardio, strength, HIIT, yoga) and identifies potentially harmful activities based on their unique health profile, thereby reducing injury risk and promoting safer fitness practices.

🔁 Pipeline Diagram

📊 Data Collection (gym_data.csv) → 🧹 Preprocessing (Imputation, Scaling, Encoding) → 🛠️ Feature Engineering (BMI_Class, HR_Burn_Ratio) → 🔀 Train/Validation/Test Split (64/16/20) → 🤖 ML Models (RF, LR, DT, SVM, KNN) + 🧠 Deep Learning (NN) → 📈 Evaluation & Comparison → 🎯 Best Model → 🌐 Deployment (GitHub Pages)

📊 Dataset Details

Source: Synthetic gym tracking data.

Size: 973 records, 15 features.

Features: Age, Gender, Weight (kg), Height (m), Max_BPM, Avg_BPM, Resting_BPM, Session_Duration (hours), Calories_Burned, Workout_Type, Fat_Percentage, Water_Intake (liters), Workout_Frequency (days/week), BMI (engineered BMI_Class and HR_Burn_Ratio).

Target: Experience_Level (1 = Beginner, 2 = Intermediate, 3 = Advanced).

Class Distribution: Beginner 41.7%, Intermediate 38.6%, Advanced 19.6%.

🤖 Models Used

Machine Learning (Scikit-learn)

  • Random Forest (n_estimators=100,200; max_depth=10,20,None)
  • Logistic Regression (C=0.1,1,10; max_iter=1000)
  • Decision Tree (max_depth=5,10,20,None)
  • Support Vector Machine (C=0.1,1,10; kernel=rbf,linear)
  • K-Nearest Neighbors (n_neighbors=3,5,7,9)

Deep Learning (TensorFlow/Keras)

  • 3-layer Feedforward Neural Network: 128 → 64 → 32 neurons
  • Activation: ReLU (hidden), Softmax (output)
  • Optimiser: Adam (learning rate 0.001, adaptive reduction)
  • Regularisation: Dropout (0.3), BatchNormalisation
  • Callbacks: EarlyStopping (patience=10), ReduceLROnPlateau (factor=0.5, patience=5)
